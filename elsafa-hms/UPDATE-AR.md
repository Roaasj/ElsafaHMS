# تحديث شامل: كل التحديثات في ملف واحد (لحد النسخة 26)

الملف ده فيه البرنامج كله بكل اللي اتعمل من أول الدفتر المحاسبي (A/B/C) لحد الصفا كاث والإيصال الإلكتروني.
اللي فات كله متضمّن، فمش محتاج تركّب أي zip قديم.

## قبل ما تبدأ
1. اقفل البرنامج (Ctrl+C في نافذة التشغيل).
2. **خد نسخة احتياطية من قاعدة البيانات** (SQL Server: Backup لـ `ElsafaHMS`).
3. خد نسخة من فولدر البرنامج القديم كمان لو حبيت.

## خطوات التركيب (على المستشفى)
1. فك الـ zip وانسخ محتواه فوق فولدر البرنامج واختار **Replace / استبدال الكل**.
2. **ما تمسحش ولا تستبدل** الحاجات دي (مش موجودة في الـ zip أصلًا): ملف `.env`، فولدر `data`، فولدر `node_modules`.
3. افتح CMD جوه فولدر البرنامج:
   ```
   cd /d <مسار الفولدر>
   npm install
   npm run db:init
   ```
   لازم تشوف: **تمام: القاعدة على النسخة 26**. (لو القاعدة عندك أقدم، الأمر بيطبّق كل التحديثات الناقصة بالترتيب لوحده، من غير ما تشغّل ملفات SQL بإيدك.)
4. شغّل البرنامج زي العادة (`start.bat`).

## لو عندك نسخة الصفا كاث
نفس الخطوات بالظبط في فولدرها (استبدل الكود فوق فولدر الكاث، من غير `.env` و`data`)، وبعدين `npm run db:init` جواه.

## اللي هتلاقيه جديد بعد التشغيل
- الدفاتر والقيود: قيود الورديات والموردين والمصروفات والأقساط، وحسابات لكل عيادة.
- الصفا كاث: ربط المرضى، طلب خدمات القسطرة، قايمة شغل الفنّي، «راح/رجع»، تحصيل مدمج بإيصالين، «الانتقال إلى الصفا كاث» بنفس الحساب.
- أدوار جديدة: «محاسب ومخزن الصفا كاث» و«محاسب عام (المنشأتين)» (بتتضاف أول ما البرنامج يشتغل).
- «الإيصال الإلكتروني»: شاشة الإعدادات والمستندات (بيئة تجربة داخلية لحد ما نفعّل الاتصال الحقيقي).
- كل الصلاحيات الجديدة من «الأدوار» ومحتاج المدير يوزّعها.

## لو حصلت مشكلة
- رجّع النسخة الاحتياطية للقاعدة والفولدر القديم، وابعتلي نص الرسالة أو صورة الشاشة.
