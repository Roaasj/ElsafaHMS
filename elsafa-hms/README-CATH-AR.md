# تشغيل نسخة الصفا كاث (نسخة مستقلة بقاعدة بيانات منفصلة)

نفس البرنامج، بس فولدر وقاعدة وبورت واسم كوكيز مختلفين، عشان الكيانين يفضلوا منفصلين تمامًا (ترقيم، إيصالات، دفاتر، نسخ احتياطي).

1. انسخ فولدر البرنامج كله (من غير `node_modules` لو حبيت) في فولدر جديد، مثلًا `C:\SafaCath`.
2. انسخ `.env.cath.example` باسم `.env` جوه الفولدر الجديد واظبط بيانات SQL Server. **اسم القاعدة لازم يكون مختلف** (`SafaCathHMS`) والبورت `3001`.
3. اعمل القاعدة الفاضية `SafaCathHMS` من SQL Server (Create Database).
4. من جوه الفولدر الجديد: `cd /d C:\SafaCath` ثم `npm install --omit=dev` ثم `npm run db:init`.
5. طبّق القالب: `npm run template -- templates/safa-cath.json`. بيحط الاسم «الصفا كاث لأبحاث القلب» (بلوجو المستشفى مؤقتًا) ويقفل المعمل والأشعة والصيدلية والتعاقدات.
6. شغّل `start-cath.bat` وافتح `http://localhost:3001`، ادخل بحساب المدير وغيّر كلمة السر.
7. **من الإعدادات ← «الأقسام المفعّلة»** تقدر تقفل أو تفتح أي قسم في أي وقت (المعمل والأشعة، الصيدلية، التعاقدات، الإقامة). القسم المقفول بيختفي من القايمة، والـ API بتاعه بيرفض لأي حد حتى المدير.
8. الخدمات فاضية: ضيفها من «الخدمات والأسعار». المخازن والأدوار من نفس شاشات البرنامج.

ملحوظة: تغيير الهوية واللوجو من «الإعدادات ← هوية المستشفى».

## ربط المرضى بين المستشفى والصفا كاث
1. اتأكد إن النسختين على نفس الشبكة وكل واحدة تفتح عنوان التانية من المتصفح (مثلًا `http://192.168.1.10:3000` و `http://192.168.1.10:3001`). لو فيه فايروول افتح البورتين.
2. في **كل نسخة**: القايمة ← «الربط مع منشأة تانية» (صلاحية `peer.manage`، للمدير). فعّل «الربط شغّال»، اكتب اسم المنشأة التانية وعنوانها.
3. اضغط «توليد مفتاح» في نسخة واحدة، **انسخه** وحطه في نفس الخانة في النسخة التانية (لازم نفس المفتاح في الناحيتين)، واحفظ الاتنين. بعدين «جرّب الاتصال».
4. من شاشة «المرضى» هتلاقي زرار «بحث في <المنشأة التانية>»: دوّر، واضغط «استيراد» (بيتسجل عندك مربوط)، أو افتح ملف مريض موجود واضغط «دوّر واربط يدويًا».
5. لو الرقم القومي واحد في النسختين، ملف المريض بيعرض «لقينا نفس الرقم القومي... ربط الملفين» وانت بتأكد بضغطة (مفيش دمج تلقائي).
6. أي تعديل في الاسم/التليفون/الرقم القومي/السن/النوع/العنوان/القريب بيتزامن للطرف التاني. لو الاتصال وقع التعديل بيستنى في طابور وبيتبعت أوتوماتيك كل دقيقة (أو من زرار «ابعت المتأخر»).
7. فك الربط من ملف المريض لصاحب صلاحية `peer.manage`.
