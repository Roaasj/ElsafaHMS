# نظام إدارة مستشفى الصفا — المرحلة الأولى كاملة + الأشعة والمعمل وحسابات الإقامة (نسخة 0.10)

- **الشريحة 1 (الاستقبال والخزينة):** ملف المريض، الزيارة الخارجية (عيادات، طوارئ، معمل، أشعة)، الدفع وإيصال A5، إلغاء الإيصال بإيصال مرتجع، الزيارات المفتوحة، وإيصالات اليوم.
- **الشريحة 2 (الإعدادات، للمدير بس):** الخدمات والأسعار (مع تاريخ كل سعر)، تصدير واستيراد إكسل بمعاينة قبل التنفيذ، الأطباء ومواعيدهم ونسبهم، المستخدمين وكلمات السر، وسجل التعديلات. وكل موظف يقدر يغيّر كلمة السر بتاعته من زرار المفتاح.

- **الشريحة 3 (الدخول والأسرّة):** لوحة الأسرّة لكل الأدوار، الدخول (داخلي/عمليات/عناية/حضانة) وإيصال التأمين، ليالي الإقامة بتتسجل لوحدها، خدمات الإقامة والعمليات والباكدج، دفعات تحت الحساب، التحويل بين الأسرّة، الخروج والفاتورة النهائية (والمتبقي آجل أو المرتجع للمريض)، المرضى المقيمين، وإعدادات الأدوار والغرف والأسرّة وأسعار الدرجات.

- **الشريحة 4 (التعاقدات والموافقات):** جهات التعاقد ومستويات الكارنيه ونسبة كل قسم، الأسعار الخاصة أو الخصم، الخدمات المستبعدة واللي محتاجة موافقة، حد أقصى للزيارة والسنة، تعاقد المريض الافتراضي، تقسيم كل بند بين الشركة والمريض في الزيارة والدخول والإيصال والفاتورة، شاشة المراجعة (اعتماد/رفض/صورة الموافقة)، النقدي المؤقت والمرتجع بعد الاعتماد، وكشف حساب الجهة وتصديره إكسل.

- **الشريحة 5 (الخزينة والورديات والتقارير):** إذن الدفع من الاستقبال للخزينة، شاشة الخزينة والإيصال اليدوي، تقفيل الوردية وعدّ النقدية والتسليم والاستلام، تقرير الخزينة اليومي بالأقسام (طباعة A4 وإكسل)، الورديات، الخصومات والآجل، ومستحقات الأطباء.

- **المرحلة 2 / الأشعة:** قايمة شغل القسم من أول الدفع لحد التسليم، تقارير السونار بالقوالب جوه البرنامج بدل الورد، متابعة المقطعية اللي بتتبعت لدكاترة برة (ملف أو لينك التقرير)، تنبيه المتأخر، والتسليم من الاستقبال.

- **المرحلة 2 / المعمل:** التحليل اللي اتدفع بيظهر في المعمل لوحده (من غير تسجيل تاني)، سحب العينة برقم وملصق باركود، إدخال النتايج بالمعدلات الطبيعية حسب النوع والسن وتلوين الشاذ، اعتماد دكتور المعمل (اختياري)، المعامل الخارجية، تقرير واحد للمريض، والتسليم. وكل التحاليل وبنودها ومعدلاتها بتتعدل.

- **حسابات الإقامة (التذكرة):** دور «الحسابات» بيكتب التذكرة اليومية لكل مريض مقيم (أدوية، مستلزمات، خدمات، زيارات، أتعاب أطباء) من أسعار الأصناف، كذا دفعة في اليوم، ومتابعة الأيام الناقصة. آخر موظف حسابات قبل الخروج «يقفل التذكرة» فالحساب يتجمد وإذن الخروج يروح للخزينة. فاتورة إجمالية وتفصيلية. الفتح تاني لمشرف الحسابات أو المدير. واللي اتنسى بعد الخروج يتسجل «مستحق لاحق»: المريض يدفعه، أو يتحمّل على موظف أو قسم.

> **مفيش Restore لأي ملف.** الملف المضغوط ده كود البرنامج، و`npm run db:init` هو اللي بيعمل القاعدة والجداول.

## المطلوب على الجهاز
- Node.js: آخر نسخة LTS من nodejs.org. أقل نسخ فيها تصحيحات أمان أكتوبر 2026: **26.12.1** أو **24.22.1** أو **22.23.4**. السيرفر بينبّه لو النسخة أقدم.
- SQL Server (أي نسخة 2016 أو أحدث، و Express ينفع للتجربة).

## تجهيز SQL Server (مرة واحدة)
- **SQL Server Configuration Manager** ← SQL Server Network Configuration ← فعّل **TCP/IP** ← أعد تشغيل خدمة SQL Server.
- لو بتستخدم اسم نسخة (زي `SQLEXPRESS`) شغّل خدمة **SQL Server Browser**، أو حدد بورت ثابت.
- **SSMS** ← خصائص السيرفر ← Security ← **SQL Server and Windows Authentication mode** ← أعد التشغيل.
- اعمل Login جديد: Security ← Logins ← New Login ← SQL Server authentication، مثلًا `elsafa_hms`، وإدّيله Server Role اسمه `dbcreator`. بعد `db:init` تقدر تشيل `dbcreator` (البرنامج بيبقى `db_owner` على `ElsafaHMS` بس لأنه هو اللي عملها).
- البرنامج بيدخل باسم وكلمة سر، **مش** بحساب الويندوز.

## التشغيل على SQL Server (البيئة التجريبية)
1. فك الملف المضغوط في فولدر، مثلًا `C:\ElsafaHMS`.
2. افتح الفولدر في CMD واكتب: `npm install`
3. انسخ `.env.example` باسم `.env` وعدّل بيانات السيرفر واسم المستخدم وكلمة السر.
   - يُفضّل مستخدم SQL مخصوص للبرنامج (مثلًا `elsafa_hms`) عنده صلاحية `dbcreator` عشان أول مرة بس، وبعد كده `db_owner` على قاعدة `ElsafaHMS` لوحدها.
4. اعمل القاعدة والجداول: `npm run db:init`
   - بيعمل قاعدة جديدة اسمها `ElsafaHMS` بترتيب `Arabic_CI_AS`، ومش بيلمس قاعدة البرنامج القديم خالص.
5. بيانات تجريبية (للبيئة التجريبية بس): `npm run seed:demo`
   - مستخدمين: `manager` و `super` و `reception` و `review`، وكلمة السر `Safa@2026`
   - خدمات وأسعار وأطباء ومواعيد ونسب للتجربة.
6. شغّل: `npm start` أو دبل كليك على `start.bat`
7. افتح من أي جهاز على الشبكة: `http://اسم-السيرفر:3000`

## تجربة سريعة من غير SQL Server
لو عايز تشوف الشكل بس على أي جهاز: خلي `DB_DRIVER=sqlite` في `.env` (أو من غير `.env` خالص)، وبعدين:
```
npm install
npm run seed:demo
npm start
```
القاعدة التجريبية بتتعمل في فولدر `data`.

## إضافة مستخدم أو تغيير كلمة السر
```
npm run user:add -- ahmed "أحمد محمد" reception كلمة_السر
```
الأدوار: `reception` موظف استقبال · `cashier` موظف خزينة · `lab` المعمل (فني/دكتور) · `radiology` قسم الأشعة (فني/دكتور) · `supervisor` مشرف الاستقبال · `reviewer` مراجع تعاقدات · `accounts` حسابات الإقامة · `accsuper` مشرف الحسابات · `storekeeper` أمين المخزن · `storeacc` حسابات المخزن · `pharmacist` الصيدلية · `nurse` تمريض/مخزن قسم · `manager` المدير (المخازن والصلاحيات الإضافية بتتحدد من الإعدادات ← المستخدمين)

## التحديث من نسخة قديمة (0.1 لـ 0.9)
1. وقّف البرنامج.
2. فك النسخة الجديدة فوق القديمة (أو في فولدر جديد وانسخ ملف `.env` القديم جواه).
3. `npm install`
4. `npm run db:init` ← بيشوف القاعدة على أنهي نسخة، وبينفذ التحديث الجديد بس (002 الدخول والأسرّة، 003 التعاقدات، 004 الخزينة والورديات، 005 الأشعة، 006 المعمل، 007 حسابات الإقامة، 008 أسعار الأدوار، 009 المخازن). **البيانات القديمة مش بتتمسح.** آمن تشغيله أكتر من مرة.
5. `npm start`

لو البرنامج اشتغل على قاعدة محتاجة تحديث، هيرفض يقوم ويقولك تشغّل `npm run db:init`.
> للتجربة السريعة على SQLite: امسح فولدر `data` وشغّل `npm run seed:demo` تاني.

## الدخول والأسرّة
- **الأدوار:** التالت (إقامة + حضانة)، الرابع، السادس (عناية + عمليات)، السابع، التامن. بتتعمل لوحدها مع التحديث، والمدير يعدّلها أو يزوّد.
- **درجات الغرف:** عادية، ممتازة، جناح، جناح ملكي (إقامة)، عناية مركزة، حضانة. **السعر والتأمين فاضيين** لحد ما المدير يدخلهم من الإعدادات ← الغرف والأسرّة. مينفعش دخول على درجة من غير سعر ليلة.
- **الغرف والأسرّة:** المدير يضيفها من نفس الشاشة: رقم الغرفة، الدور، الدرجة، وعدد الأسرّة.
- **الدخول:** الرقم القومي والعنوان وقريب للطوارئ إجباريين. التأمين بييجي لوحده حسب الدرجة، والموظف يقدر يزوده بس، والمدير يقدر يقلله.
- **الليالي:** ليلة لكل يوم من يوم الدخول، بتتسجل لوحدها. سعر اليوم حسب السرير اللي المريض فيه آخر اليوم. يوم الخروج بيتحسب لو الخروج بعد «ميعاد حساب يوم الخروج» (12:00 افتراضي، والمدير يغيّره)، وأقل حاجة ليلة واحدة. تغيير سعر الدرجة بيسري على الليالي الجاية بس.
- **الباكدج:** خدمة في قسم العمليات وليها «ليالي شاملة»، فأول الليالي دي بتبقى بصفر.
- **من الطوارئ للدخول:** زرار «حوّله دخول» في الزيارة. الخدمات اللي لسه ما اتدفعتش بتنتقل لحساب الإقامة والزيارة بتتقفل.
- **الخروج:** الحساب كله ناقص المدفوع (التأمين والدفعات) ناقص أي خصم بموافقة المدير. لو فاضل فلوس: نقدي أو فيزا، أو جزء آجل بموافقة المدير وسبب. لو التأمين أكبر: مرتجع نقدي للمريض. السرير بيبقى «تحت التنظيف» لحد ما حد يعلّمه فاضي.
- **إلغاء الخروج:** المدير بس، بإيصال عكسي، والمريض بيرجع على سريره.
- **نسب الأطباء على خدمات الإقامة** بتتحسب عند الخروج على المبلغ بعد الخصم.
- المريض الخارجي (العيادات/الطوارئ) مش بيشوف خدمات الإقامة والعمليات.
- **اختصار:** `F3` لوحة الأسرّة.

## الإعدادات (المدير)
- **الخدمات والأسعار:** ضيف خدمة (الكود بيتعمل لوحده لو سبته فاضي)، غيّر السعر بدوسة على السعر، ووقف خدمة من غير ما تتمسح. كل تغيير سعر بيتسجل بتاريخه واسم اللي غيّره، والإيصالات القديمة مش بتتغير.
- **إكسل:** «تصدير إكسل» بينزّل القايمة الحالية (فيها قوايم منسدلة للقسم والدفع ونعم/لا). عدّل فيها وارفعها من «استيراد من إكسل»، وهتشوف قبل التنفيذ: الجديد، اللي هيتعدل (والسعر القديم والجديد)، واللي فيه غلط ومش هيتنفذ.
- **الأطباء:** المواعيد في الأسبوع (أكتر من موعد في اليوم، و«نسخ للكل»)، والنسبة: عامة، ولكل قسم، ولخدمة معينة. الأولوية: الخدمة ← القسم ← العامة. النسبة بتتحفظ في البند وقت التسجيل.
- **المستخدمين:** إضافة وتعديل الدور ووقف الحساب (بيخرج فورًا)، وكلمة سر جديدة. مينفعش المدير يوقف نفسه، ولازم يفضل مدير واحد على الأقل.
- **سجل التعديلات:** كل الحركات المهمة (الإيصالات، الإلغاء، الخصم، الأسعار، الإعدادات) باسم اللي عملها ووقتها.

## القواعد اللي بتحمي الفلوس
- كل المبالغ بتتحسب بالقروش في الكود وبتتخزن `DECIMAL(12,2)`، وفيه شرط في القاعدة إن (نقدي + فيزا + آجل = الصافي) و(الإجمالي − الخصم = الصافي).
- مفيش حذف لإيصال: الإلغاء بيعمل إيصال مرتجع بالسالب بسبب، والبنود بتتلغي، ونسبة الدكتور بتتعكس.
- أرقام الملفات والزيارات والإيصالات متسلسلة من القاعدة (جدول `Counters` جوه نفس المعاملة)، فمافيش رقمين زي بعض.
- السعر ونسبة الدكتور بيتحفظوا في البند وقت التسجيل، فتغيير الأسعار بعدين ما يأثرش على القديم.
- الخصم لازم سبب واسم المدير، والآجل لازم اسم المدير، وكله متسجل في `AuditLog`.
- موظف الاستقبال يلغي إيصالاته هو بس وورديته لسه مفتوحة. بعد كده المشرف أو المدير.
- إعادة الطباعة بتطلع مكتوب عليها «نسخة» وبتتسجل.

## التعاقدات (قايمة «التعاقدات»)
- **الجهات (المدير):** «جهة جديدة» ← الاسم والنوع ومدة التعاقد، طريقة الأسعار (أسعار المستشفى / أسعار خاصة / خصم %)، حد أقصى للزيارة أو السنة، والمستندات المطلوبة. تحتها جدول **مستويات الكارنيه**: لكل مستوى نسبة تحمّل الجهة في الكشف والطوارئ والمعمل والأشعة والإقامة والعمليات (الفاضي = 0% على المريض). وتحت خالص كل خدمة: «متغطية» أو «محتاجة موافقة» أو «مش مغطاة»، ولو الأسعار خاصة بتكتب سعر الجهة للخدمة ولليلة كل درجة.
- **المريض:** من ملفه ← «ضيف تعاقد»: الجهة والمستوى ورقم الكارنيه. أي زيارة أو دخول جديد بياخده لوحده، وتقدر تغيّره من الشريط اللي فوق الزيارة أو من ملخص الدخول. لو التعاقد منتهي، الزيارة بتتفتح نقدي وبيطلع تنبيه.
- **الحساب:** كل بند بيبان فيه القيمة ونصيب الشركة واللي على المريض، والمريض بيدفع نصيبه بس. الإيصال والفاتورة النهائية فيهم عمود «نصيب التعاقد». تأمين الدخول بيقل بنسبة تحمّل الجهة للإقامة (تعاقد 100% = من غير تأمين).
- **خدمة محتاجة موافقة:** بيطلع شباك: لو معاك رقم الموافقة (وصورتها اختياري) المريض يدفع نصيبه والبند «مستني المراجعة». لو لسه مفيش موافقة اختار **نقدي مؤقت**: المريض يدفع كله، ولما تتعتمد بيظهر في الزيارة «للمريض مرتجع» وزرار «اصرف واطبع».
- **المراجعة (مراجع التعاقدات):** كروت الموافقات المستنية مع الصورة ← «اعتماد» أو «رفض» بسبب. الرفض بعد ما المريض دفع نصيبه بيضيف بند «فرق رفض موافقة» على الزيارة (دين على المريض). رفض موافقة الدخول بيحوّل حساب الإقامة كله نقدي. العدد بيبان جنب «التعاقدات» في القايمة وفي الرئيسية.
- **كشف حساب جهة:** اختار الجهة والفترة ← كل البنود اللي على الجهة (بعد الدفع أو الاعتماد) بالمريض والكارنيه ورقم الموافقة، و«إكسل» للمطالبة الشهرية. الإلغاء بيطلع سطر بالسالب.
- **قرارات اتاخدت (تقدر تغيّرها):** نسبة الدكتور على السعر الكامل والجزء اللي على الشركة بيتسجل «مستحق بعد التحصيل»؛ الرفض بيتحوّل على المريض؛ الآجل بموافقة المدير بس.

## الخزينة والورديات (الشريحة 5)
- **مين بيقبض؟** لما موظف خزينة يدوس «ابدأ الوردية» (الصباحي 8–4 أو المسائي 4–10)، زرار الدفع عند الاستقبال بيبقى **«اعمل إذن دفع للخزينة»**: البنود بتتحجز، ويتطبع إذن صغير برقم كبير، والمريض ياخده للخزينة. الخصم والآجل بيتعملوا عند الاستقبال بموافقة المدير زي الأول. لما مفيش خزينة مفتوحة (السهر) الاستقبال بيقبض بنفسه. البرنامج بيعرف لوحده.
- **نفس الكلام في الدخول:** تأمين الدخول، الدفعات، والخروج (المريض بيفضل على سريره لحد ما الخزينة تحصّل الباقي أو تصرف المرتجع)، ومرتجع النقدي المؤقت.
- **شاشة الخزينة:** الأذونات المستنية بتظهر لوحدها (بتتحدث كل 8 ثواني). اكتب رقم الإذن واضغط Enter، اختار نقدي/فيزا/الاتنين، اكتب رقم الإيصال اليدوي، و«حصّل واطبع الإيصال». الإيصال بيطلع باسم الخزينة وفي ورديتها. أي إذن يتلغي بسبب (من اللي عمله أو الخزينة أو المشرف) والبنود بترجع.
- **تقفيل الوردية:** من القايمة «تقفيل الوردية»: البرنامج بيحسب النقدية المفروضة (المحصّل − المصروف + اللي استلمته من ورديات)، تكتب اللي في الدرج فعلًا، ولو فيه فرق لازم سبب، وتختار هتسلّم لمين (خزينة/مشرف/مدير)، ويطبع «تسليم وردية». المستلم بيدوس «استلمت» والمبلغ بيدخل درجه.
- **يوم الخزينة:** بيبدأ 8 الصبح (مسموح الاستلام بدري من 7)، والسهر بيتحسب على اليوم اللي بدأ فيه.
- **التقارير:** تقرير الخزينة اليومي (كل الورديات أو وردية واحدة) مقسم بالأقسام: الإيصال، اليدوي، الوقت، المريض، الخدمة، نقدي/فيزا/آجل، وإجمالي كل قسم والإجمالي الكلي، وطباعة A4 وإكسل. والورديات، والخصومات والآجل، ومستحقات الأطباء (للمشرف والمدير).
- **إعدادات المدير (الإعدادات ← الغرف):** تشغيل/إيقاف أذونات الخزينة، وخلّي رقم الإيصال اليدوي إجباري.

## الأشعة (قايمة «الأشعة»)
- **قايمة الشغل:** أي خدمة أشعة اتدفعت (أو اتضافت لحساب مريض داخلي) بتظهر لوحدها في «مستني الفحص». أربع خانات فوق: مستني الفحص، مستني التقرير (والمتأخر بالأحمر)، جاهز للتسليم، اتسلّم النهارده. وفلتر بالنوع: سونار، عادية، مقطعية، رنين، ماموجرام.
- **الفني/الدكتور:** «اتعمل» (ويكتب البيانات الإكلينيكية لو فيه) ← الفحص بيروح «مستني التقرير» بوقت متوقع (سونار ساعتين، مقطعية 24 ساعة).
- **تقرير السونار:** صفحة الفحص فيها محرر زي الورد (عريض، نقط، أرقام، IMPRESSION) والقوالب على الجنب: دوسة على القالب والدكتور يعدّل. «احفظ مسودة» (Ctrl+S، وبيتحفظ لوحده كل دقيقة) و«اعتمد التقرير» ← بيتطبع A4 بشكل المستشفى باسم الدكتور. التعديل بعد التسليم للمدير بس.
- **المقطعية والرنين:** «اتبعت للدكتور» (لمين)، ولما التقرير يرجع: ارفع الـ PDF/الصورة، أو حط لينك التقرير من برنامج الأشعة على الويب.
- **العادية:** ممكن تتسلّم من غير تقرير.
- **التسليم:** الاستقبال يدوس «سلّم» ويكتب مين استلم، وبيطبع التقرير. وفي ملف المريض كارت «الأشعة» بكل فحوصاته وحالتها.
- **القوالب:** تبويب «القوالب» (المدير ودكتور الأشعة): 11 قالب جاهز (بطن وحوض، حوض سيدات، حمل، غدة، ثدي، كلى، صفن، صدر، مقطعية، ماموجرام) تتعدل أو تضيف عليها.
- **نوع الأشعة للخدمة:** البرنامج بيعرفه من الاسم (سونار/مقطعية/رنين...)، والمدير يحدده من الإعدادات ← الخدمات لو الاسم مش واضح.

## المعمل (قايمة «المعمل»)
- **قايمة الشغل:** كارت لكل مريض فيه تحاليله ولون كل تحليل حسب حالته. أربع خانات: مستني السحب، في المعمل (والمتأخر بالأحمر)، جاهز للتسليم، اتسلّم النهارده. دوّر بالاسم أو رقم الملف أو رقم العينة.
- **سحب العينة:** «اتسحبت العينة» ← رقم عينة واحد للمريض (يبدأ من 100001) وملصقات باركود 50×25مم (ملصق لكل أنبوبة: EDTA، Plain، Citrate...) بتتطبع لوحدها.
- **النتايج:** «النتايج» بيفتح كل تحاليل المريض في صفحة واحدة. كل بند جنبه الوحدة والمعدل الطبيعي المناسب لنوع المريض وسنه (فيه معدلات أطفال لبعض التحاليل). اكتب الرقم واضغط Enter للبند اللي بعده، والعالي/الواطي/الغير طبيعي بيتلوّن وانت بتكتب. «احفظ» (Ctrl+S) مسودة، و«النتيجة جاهزة» ← بتتطبع بشكل المستشفى (A4، كل الأقسام في ورقة واحدة، والبنود الفاضية مش بتطلع).
- **الاعتماد (اختياري):** من الإعدادات ← الغرف ← «المعمل». لو اتفعّل، الفني بيخلّص النتيجة ودكتور المعمل يدوس «اعتمد» قبل الطباعة النهائية والتسليم (قبلها بتتطبع «نتيجة مبدئية»).
- **المعمل الخارجي:** التحليل اللي متعلّم «معمل خارجي» ← «اتبعت» (لمين وإمتى ترجع) ← «ارفع النتيجة» PDF/صورة، أو اكتبها لو جت ورقة.
- **التسليم:** الاستقبال يدوس «سلّم» للجاهز بس (والباقي يتسلّم بعدين) ويطبع. وفي ملف المريض كارت «التحاليل».
- **التحاليل:** تبويب «التحاليل»: 27 تحليل جاهز (صورة دم، سكر، تراكمي، كبد، كلى، دهون، أملاح، كالسيوم، CRP، ASO، RF، غدة، فيتامين د، فيريتين، حمل، سيولة، فيروسات، فصيلة، بول، براز، جرثومة المعدة...). لكل تحليل: الاسم في التقرير، القسم، العينة والأنبوبة، الوقت المتوقع، الخدمة المربوطة في الاستقبال، والبنود (رقم بمعدلات حسب النوع والسن، أو اختيار بقيمة طبيعية، أو نص، أو عنوان). **المعدلات قيم مرجعية شائعة كبداية، ولازم دكتور المعمل يراجعها قبل التشغيل.**
- **ربط الأجهزة:** الخطوة الجاية بعد ما نعرف أسماء وموديلات الأجهزة.

## حسابات الإقامة (قايمة «حسابات الإقامة»)
- **الدورة:** الريسيبشن يسجل الدخول ويستلم التأمين ← الحسابات تكتب التذكرة أول بأول (كل ما الورقة تنزل) ← آخر موظف حسابات قبل الخروج يقفل التذكرة ← الخزينة تحصّل ← المريض يخرج والسرير يبقى «تحت التنظيف».
- **نظام التذكرة** شغال افتراضي. وهو شغال: الاستقبال مايضيفش بنود على المقيم، وزرار «خروج» مش بيظهر غير بعد القفل. المدير يقدر يقفله من الإعدادات ← الغرف ← «حسابات الإقامة».
- **لوحة الحسابات:** كل المقيمين متقسمين بالدور: اتكتبله النهارده ولا لأ، الأيام الناقصة، المقفول ومستني الخزينة. وفي لوحة الأسرّة علامة صغيرة على اللي لسه ما اتكتبلوش تذكرة النهارده.
- **كتابة التذكرة:** اختار اليوم (النهارده افتراضي، والسهر بيتحسب على اليوم اللي بدأ فيه) ورقم الورقة لو موجود. اكتب اسم الصنف واضغط **Enter**، اكتب العدد و**Enter**، وكمّل. **كل سطر بيتحفظ لوحده أول ما يتكتب** (ومفيش زرار حفظ)، وتعديل العدد بيتحفظ أول ما تسيب الخانة. السطور بتتجمع في «دفعة» واحدة لحد ما تدوس «ورقة جديدة» أو تغيّر اليوم. السطر اللي لسه كاتبه (أقل من ربع ساعة) بيتشال من غير سبب، وغير كده بسبب. **Alt+1..5** للتنقل بين أدوية/مستلزمات/خدمات/زيارات/أتعاب. لو كتبت اسم صنف في التبويب الغلط بيلاقيه في التاني. الأصناف اللي اتكتبت للمريض قبل كده بتظهر كزراير سريعة.
- **الأسعار:** الأدوية والمستلزمات من «الأصناف»، والخدمات من قايمة الخدمات. الزيارات والأتعاب خدمات (إقامة أو عمليات) متعلّمة «زيارات» أو «أتعاب أطباء»، ولازم دكتور. الخدمة اللي «سعرها مفتوح» (زي أتعاب الجراح) الحسابات بتكتب مبلغها.
- **التعاقدات:** الجهة تقدر تغطي الأدوية والمستلزمات بنسبة زي أي قسم (عمودين جداد في المستويات)، وجهات الخصم بتاخد نفس الخصم على الأصناف.
- **شيل بند:** بسبب، وقبل القفل بس. والعملية متسجلة باسم الموظف.
- **قفل التذكرة:** بيوريك الحساب بالبنود والمطلوب، وبينبّه لو فيه أيام من غير تذكرة أو موافقات تعاقد لسه مستنية أو إذن دفع مستني في الخزينة. بعد القفل: الليالي بتقف على وقت القفل، ولو الخزينة شغالة إذن الخروج بيروح لها لوحده، ولو مفيش خزينة (السهر) الاستقبال يحصّل ويخرّج.
- **فتح التذكرة:** مشرف الحسابات أو المدير، بسبب. إذن الخروج المستني بيتلغي.
- **الفاتورة:** «إجمالية» (A5: الإقامة، الخدمات، الأدوية، المستلزمات، الأتعاب، الزيارات) و«تفصيلية» (A4: كل بند بيومه). بتتطبع لوحدها بعد القفل.
- **المستحقات اللاحقة:** «سجّل حاجة اتنست» ← المريض اللي خرج + البند + إيه اللي حصل. مشرف الحسابات ياخد القرار: **المريض هيدفع** (البند يتضاف على حسابه وإذن دفع للخزينة) أو **على موظف** أو **على القسم** أو إلغاء. وفيه ملخص بالتحميل على مين.
- **الأصناف:** تبويب «الأصناف»: إضافة وتعديل ووقف، وتصدير إكسل ← عدّل الأسعار ← استيراد بمعاينة قبل التنفيذ (الصنف بيتعرف بالكود أو بالاسم). المدير ومشرف الحسابات بس.

## أسعار الأدوار (الإعدادات ← «أسعار الأدوار»)
- نفس الخدمة ونفس اسم الدرجة، وكل دور بسعره. جدول لسعر الليلة (الدرجات × الأدوار) وجدول للخدمات والزيارات (الإقامة، العمليات، المعمل، الأشعة). اكتب السعر في خانة الدور، والخانة الفاضية = السعر الأساسي. Enter ينزل للخانة اللي تحت، والحفظ أول ما تسيب الخانة. الأخضر أرخص من الأساسي، والبرتقاني أغلى.
- البرنامج بيعرف المريض كان في أنهي دور يوم التذكرة وياخد السعر لوحده، وفي شاشة التذكرة بيبان «أسعار الدور 8». لو اتنقل بين دورين، كل يوم بسعر دوره (الليالي كمان).
- الأتعاب سعرها واحد في كل الأدوار، والأدوية والمستلزمات كمان.
- مريض التعاقد: سعر الشركة الخاص الأول، ولو مالهاش سعر للخدمة ياخد سعر الدور (وجهات الخصم بتاخد الخصم من سعر الدور).
- تغيير السعر بيسري على اللي هيتكتب من دلوقتي بس. والعيادات والطوارئ مالهاش دعوة.
- تصدير إكسل ← عدّل ← استيراد بمعاينة قبل التنفيذ.

## المخازن (قايمة «المخازن»)
- **المخازن:** مخزن الأدوية الرئيسي، مخزن المستلزمات الرئيسي، الصيدلية، ومخزن لكل دور (بيتعملوا لوحدهم). المدير يزوّد مخازن للعيادات والأقسام من تبويب «تعريف المخازن»، ويحدد كل مخزن بيشيل أدوية ولا مستلزمات ولا الاتنين، ومربوط بأنهي دور.
- **مين بيشتغل على إيه:** أمين المخزن والصيدلية والتمريض كل واحد على المخازن اللي المدير ربطه بيها (الإعدادات ← المستخدمين). حسابات المخزن والمدير على كل المخازن.
- **الوحدات:** كل صنف ليه أصغر وحدة (السعر عليها: قرص، أمبول، سم، قطعة)، ووحدة وسطى وكبيرة اختياري (شريط = 7 قرص، علبة = 14 قرص، متر = 100 سم). الرصيد بيتحسب بأصغر وحدة وبيظهر «2 علبة + 1 شريط + 3 قرص». والصنف ليه «حد الطلب».
- **الاستلام من الموردين (حسابات المخزن):** المورد ورقم الفاتورة وتاريخها، والكمية بأي وحدة، وسعر الشراء والتشغيلة والصلاحية لكل صنف. و«رصيد أول المدة» لكل مخزن عند التشغيل. الصلاحية المنتهية مرفوضة.
- **الصرف:** دايمًا من الأقرب انتهاءً، والتشغيلة والصلاحية بيتنقلوا مع التحويل.
- **التحويلات:** المخزن الفرعي يطلب من الرئيسي أو الصيدلية ← المخزن يصرف (ويقدر يصرف أقل من المطلوب) ← الفرعي يستلم ← المخزن يأكد. وكمان المخزن يقدر يحوّل من غير طلب. اللي اتصرف ولسه ما اتستلمش يتلغي والرصيد يرجع.
- **التحويل المباشر:** صلاحية المدير بيفعّلها لمستخدم بعينه: التحويل يتسجل في المخزن التاني على طول من غير استلام.
- **الرصيد السالب:** صلاحية المدير بيفعّلها لمستخدم بعينه: يصرف حتى لو الرصيد صفر أو سالب. أول استلام بعد كده بيسدد السالب. من غيرها البرنامج بيرفض ويقول الموجود كام.
- **التذكرة:** الأدوية والمستلزمات اللي الحسابات بتكتبها بتتخصم من مخزن الدور اللي المريض فيه يوم التذكرة، والشيل أو تقليل العدد بيرجّعها لنفس التشغيلة. الحسابات بتختار الوحدة (علبة/شريط/قرص) وبتشوف «متاح كام» في مخزن الدور وهي بتكتب. المستحق اللاحق بيتخصم من مخزن دور الخروج، وإلغاؤه بيرجّعه. المدير يقدر يقفل الخصم من الإعدادات ← الغرف ← «حسابات الإقامة» (مثلًا لحد ما رصيد أول المدة يتدخل).
- **الأرصدة:** لكل مخزن (أو كل المخازن لحسابات المخزن): فيها رصيد، تحت حد الطلب، قربت تنتهي (3 شهور)، سالب. ودوس على أي صنف يفتح كارت الصنف: الرصيد في كل مخزن، التشغيلات، وآخر الحركات.

## الصرف من الأقسام والصيدلية والجرد (v0.11)
- **مخازن الأقسام:** بتتعمل لوحدها: العمليات، العناية، الحضانة، الطوارئ، العيادات، الأشعة، المعمل. وأي مخزن جديد يتضاف من «تعريف المخازن» ← «مخزن جديد»، وتحدد هو مخزن قسم إيه أو مربوط بأنهي دور.
- **التذكرة من أكتر من مخزن:** في التذكرة خانة «اتصرف من». الافتراضي مخزن الدور (أو العناية/الحضانة لو السرير فيهم)، والحسابات تقدر تختار مخزن العمليات مثلًا لمريض جاي من العمليات على الدور الرابع. تغيير المخزن بيبدأ دفعة جديدة، وكل دفعة مكتوب عليها اتصرفت من أنهي مخزن.
- **الصرف على الزيارة (الطوارئ والعيادات):** في شاشة الزيارة تبويب «أدوية ومستلزمات». الاستقبال بيصرف من أي مخزن مربوط بيه (مثلًا الطوارئ والعيادات كلها)، والمبلغ بيتحسب على المريض وبيدفعه مع باقي الزيارة. الشيل أو إلغاء الإيصال بيرجّع الصنف للمخزن. لو المريض اتحوّل دخول، البنود بتتنقل للتذكرة كأدوية ومستلزمات.
- **الصيدلية:** الصيدلي ليه شاشة «الصيدلية»: يدوّر على المريض أو «عميل جديد» بالاسم بس، ويبيع بالعلبة أو الشريط أو القرص، نقدي أو تعاقد. الصيدلي بيحصّل بنفسه حتى والخزينة شغالة، ويسلّم آخر شفته من «تقفيل الوردية». وفيها «بيع النهارده».
- **المرتجع:** على أي صنف مدفوع (صيدلية أو زيارة) زرار «مرتجع»: العدد والسبب، والفلوس بترجع نقدي بإيصال مرتجع، والصنف بيرجع لنفس التشغيلة. (صلاحية «stock.return»: الصيدلي والمشرف والمدير).
- **الجرد:** من «المخازن ← الجرد والإعدام ← ابدأ جرد». المخزن بيقف (مفيش صرف ولا تحويل ولا استلام) وبيظهر عليه شريط «واقف للجرد». تطبع «ورقة العد» من غير الرصيد، تعدّ يدوي وتكتب العدد (بيتحفظ لوحده)، وتضيف صنف لقيته ومش متسجل، وتسلّم للمدير. المدير يشوف الرصيد والفرق بالقيمة، ويعتمد (الرصيد يتظبط) أو يرجّعه للعد أو يلغيه.
- **الإعدام:** من كارت الصنف ← التشغيلة ← «إعدام» بالكمية والسبب (منتهي، مكسور، تالف…)، وكل الإعدام بقيمته في «الجرد والإعدام ← الإعدام».
- **ربط الموظفين بالمخازن:** أي مستخدم (مش بس المخازن) يتربط بمخزن أو أكتر من الإعدادات ← المستخدمين.

## تقارير المخزن (v0.12) — «المخازن ← التقارير»
لحسابات المخزن والمدير (والصيدلي يشوف بيع الصيدلية بس). كل تقرير ليه زرار «إكسل».
- **قيمة المخزون:** القيمة بالتكلفة (تكلفة التشغيلة، وإلا آخر سعر شراء) وبسعر البيع والربح المتوقع، لكل مخزن، وأغلى الأصناف في المخزون. دوس على مخزن يفتح تفاصيله، أو على صنف يفتح حركته.
- **استهلاك الأقسام:** المصروف للمرضى (التذكرة والمستحق اللاحق والزيارة وبيع الصيدلية، بعد طرح اللي رجع) بالتكلفة وبسعر البيع لكل مخزن، والإعدام وفروق الجرد، أو «بالصنف». بفترة (النهارده، 7 أيام، الشهر، السنة، أو من/لـ).
- **بيع الصيدلية:** الصافي وعدد الفواتير والمتوسط، المرتجع، النقدي والفيزا، اللي على التعاقدات، باليوم وبالصيدلي، أو بالصنف بالتكلفة والربح.
- **الصلاحية:** المنتهي واللي هينتهي خلال 30/90/180 يوم/سنة بقيمته، ومنه على كارت الصنف للإعدام.
- **الراكد:** أصناف ليها رصيد ومفيش منها صرف من 30/60/90/180 يوم (الصنف اللي لسه داخل جوه المدة مش بيتحسب).
- **حركة صنف:** رصيد أول الفترة، كل حركة (استلام، تحويل، صرف، بيع، مرتجع، جرد، إعدام) بالرصيد بعدها، ورصيد آخر الفترة — لمخزن واحد أو كل المخازن.

## حسابات التعاقدات والمطالبات (v0.13) — دور «حسابات التعاقدات»
- **التشخيص:** الاستقبال بيكتبه وقت التسجيل: في الزيارة جنب اسم الجهة، وفي الدخول تحت التعاقد (وبيتعدّل من صفحة الدخول).
- **الحالات:** كل زيارة اتدفعت أو دخول خرج على جهة بيبقى «حالة» لوحده. الخارجي على شهر الزيارة، والداخلي على شهر الخروج. المبلغ على الجهة = اللي اتسجل على حسابها بعد أي إلغاء أو اعتماد أو تسوية.
- **الشهر:** كارت لكل جهة: عدد الحالات (خارجي وداخلي)، المبلغ، شريط المراجعة، وحالة المطالبة.
- **المراجعة:** قايمة الحالات على اليمين وتفاصيل الحالة على الشمال. تعدّل رقم الكارنيه والتشخيص وأرقام وتواريخ الموافقات وترفع صورها والمستندات، والحفظ لوحده. «تمام» أو Enter بتعلّم الحالة وتفتح اللي بعدها، والأسهم للتنقل. البرنامج بينبّه لو الكارنيه أو التشخيص أو رقم الموافقة ناقص.
- **ملاحظة:** الحالة الناقصة بتترجع للاستقبال (بتظهر له «ملاحظات التعاقدات» بعدّاد)، يصلّحها ويدوس «اتصلحت» فترجع للمراجعة. ومش بتدخل المطالبة لحد كده.
- **التسوية:** لو نصيب الشركة في بند غلط، تكتب المبلغ الصح والسبب. إيصال المريض مش بيتغير، والفرق على المستشفى.
- **التأجيل:** «أجّل» بتنقل الحالة للشهر الجاي، و«رجّعها» ترجّعها لشهرها.
- **المطالبة:** «اعمل المطالبة» بتعمل مسودة برقم فيها كل الحالات اللي اتراجعت (وأي حالة قديمة لسه عليها فلوس). المسودة بتتحدث لوحدها. الطباعة: ورقة Cover (الجهة، الشهر، الخارجي والداخلي وعدد الحالات، الإجمالي بالحروف، التوقيعات) وبعدها التفصيلي: كل حالة بالكارنيه والدرجة والتشخيص وبنودها بتاريخ كل خدمة. وإكسل بورقتين.
- **الإرسال:** «اتبعتت للشركة» بتاريخ الإصدار، والمطالبة بتتقفل. أي فرق بعد كده بيطلع «فرق» في المطالبة اللي بعدها (تكميلية). المدير بس يفتح المطالبة المبعوتة لو مفيش عليها شيك.
- **الشيك والمرفوضات:** تسجيل شيك أو أكتر (الرقم والبنك والتاريخ والمبلغ)، والمرفوض قدام كل بند بالسبب (المستشفى بتتحمله). الحالة: اتبعتت ← اتدفع جزء ← خلصت. وتقرير «المرفوضات» بالجهة والسبب.

## الحسابات العامة (نسخة 0.14)
دور جديد «الحسابات العامة» (مستخدم تجربة `fin`) والمدير. الشاشة: `#/finance` (صرف الدكاترة، الموردين، المصروفات، الأقساط، الشيكات، إذون الصرف)، وشاشة المدير `#/dash`.
- **صرف الدكاترة:** مستحق كل دكتور لحد آخر الشهر المختار، ضريبة 5% (تتغير من «إعدادات الصرف»)، وكشف طباعة بالتوقيع. نصيب الشركات من الأتعاب بيستنى «حرّر» بعد ما الشركة تدفع.
- **إذن الصرف النقدي:** أي دفع نقدي (دكتور، مصروف، مورد، قسط) بيعمل إذن، والخزينة تدوس «صرفت» فيتخصم من درج ورديتها ويظهر في تقفيلها.
- **الموردين:** فاتورة (ممكن من استلام المخزن) بميعاد سداد، دفع بنكي أو شيك أو نقدي، وتنبيه للمتأخر.
- **المصروفات:** بنود، ومن غير صلاحية «مصروف مباشر» (من إدارة المستخدمين) بتستنى موافقة المدير.
- **الأقساط:** جدول أقساط شهري بتعديل أي قسط، ودفع بنكي أو شيك أو نقدي.
- **الشيكات المستحقة:** شيكات الموردين والأقساط لحد ما تتصرف من البنك.
- **شاشة المدير:** إيراد، مصروفات، شيكات مستحقة، أقساط، مستردات، ويوم بيوم.
- تحديث القاعدة `012_finance.sql` (ما اتجربش على SQL Server حقيقي).

## الإعدادات العامة وهوية المستشفى (نسخة 0.15)
البرنامج بقى «محرّك» والمستشفى بيانات: الاسم واللوجو والألوان والورديات والترقيم بتتغيّر من الشاشة من غير كود. الشاشة: **الإعدادات ← إعدادات عامة** (للمدير).
- **الهوية:** اسم المستشفى، السطر تحت الاسم، لوجو (رفع صورة)، لون أساسي ولون مكمّل (باقي الدرجات بتتولد منهم تلقائي، وفيه معاينة مباشرة قبل الحفظ)، وتذييل بيظهر في كل ورقة مطبوعة. الألوان والاسم واللوجو بتتغيّر في الشاشات والطباعة وملفات الإكسل.
- **الوقت والورديات:** المنطقة الزمنية، بداية يوم الخزينة، مواعيد وأسماء 3 ورديات، ومدة اعتبار الخزينة شغالة.
- **كل الإعدادات المتفرقة** (طريقة التحصيل، الإيصال اليدوي، ميعاد الخروج، اعتماد المعمل، نظام التذكرة، ضريبة الدكاترة، يوم الصرف) اتجمعت هنا في مجموعات.
- **الترقيم:** لكل عدّاد (ملف، زيارة، إيصال…) تحدد الرقم الجاي (مفيد لو بتكمّل من برنامج قديم). مينفعش يرجع لورا.
- **أي إعداد جديد في المستقبل** بيتسجل في `src/lib/settings-registry.js` وبيظهر في الشاشة لوحده.
- **قالب بداية:** `templates/elsafa.json` فيه هوية الصفا وورديات. بيتطبّق بـ `npm run template -- templates/elsafa.json` (والبيانات التجريبية بتطبّقه أوتوماتيك). لمستشفى تانية: انسخ الملف وغيّر القيم، أو غيّرها من الشاشة مباشرة.
- اللوجو بيتخزن في `data/branding` (متضافة في النسخ الاحتياطي مع `data`). ما فيش تحديث جديد للقاعدة في النسخة دي (لسه 012).
